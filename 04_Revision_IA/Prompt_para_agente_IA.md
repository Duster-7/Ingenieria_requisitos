# Prompt utilizado para la revisión de IA

Actúa como un ingeniero senior de requisitos de software. Revisa el archivo `README.md` de este proyecto (SRS de MediGuard IoT) pensando en que será utilizado por un equipo de desarrollo para construir el software.

Evalúa:

1. Si los requisitos funcionales están redactados de forma clara, verificable y sin ambigüedades.
2. Si los requisitos no funcionales tienen métricas y métodos de prueba suficientes.
3. Si la priorización MoSCoW es coherente.
4. Si existe trazabilidad entre necesidades, requisitos, casos de uso, modelos y pruebas.
5. Si los casos de uso y diagramas son consistentes con los requisitos.
6. Si faltan escenarios alternos, errores, excepciones o condiciones límite.
7. Si un desarrollador podría implementar los requisitos sin tener que inventar información crítica.
8. Identifica problemas críticos y propone correcciones concretas sin inventar datos clínicos que no estén definidos.

Entrega un dictamen final en dos niveles:
- **Apto como entrega académica**: Sí/No.
- **Listo para construcción de software real**: Sí/No.

Explica los principales hallazgos y prioriza las correcciones necesarias.
